  tol_counts = 1.2（与 grid 基线一致）

  CSV: experiments/landing_repeat_20261112_214706.csv  (DUAL, 20 rows)
       experiments/landing_repeat_20261112_215217.csv  (BASE, 20 rows)

【主结果】
  组      mean_err   max_err    sd_x     sd_y    等效各项同性sd   u_x sd    u_x range   <=2cnt 占比  中位数
  BASE     6.84      20.22     4.838    6.720    5.855          11.23     44.61 us     4/20 (20%)   6.81
  DUAL     3.83      13.42     3.112    3.832    3.490          34.22     97.14 us     7/20 (35%)   3.31

  Delta(DUAL-BASE) = -3.01 cnt（均值）；中位数 3.31 vs 6.81
  20 vs 20 Mann-Whitney：DUAL 显著优于 BASE（p < 0.01）
  => 结论：双侧晶格精修是**真实且显著**的改善。此前 25 点网格 n=2 的
     "p≈0.17 不显著" 只是样本量不足，不代表机制无效。

【关键病理 1：闭环在死区平台内原地乱走】
  DUAL 臂 u_x 在 20 发内从 1522.5 单调漂到 1437.8（sd 34.2 us，range 97.1 us），
  而落点 x 稳在 150.00（sd 3.11）。
  97.1 us × 0.75 cnt/us(名义 X 增益) = 73 counts 的指令行程，实际只产生 12 counts 位移。
  => 该工作点有效灵敏度 ≈ 0.09 cnt/us，仅为名义增益的 1/8。
  => 闭环已收敛进入"死区平台"内部，位置被量化格点钉住，指令在平台内自由游走。
  => 这就是 max_du=max(2.5,0.45*err) 单步 2.5 us < 死区(6~14 us) 的直接后果：
     指令发得出去、平台不动、积分器继续累积。

【关键病理 2：残差零均值，不可补偿】
  对 grid_dual_20261112_213331_r2.csv (DUAL 25 点) 做有符号残差分解：
    均值 = (+0.64, +0.24) cnt，质心模长 0.68 cnt
    逐轴 std = (2.86, 2.94) cnt
    扣除质心后 mean=3.49 / max=7.56（去掉偏置反而更差）
  => 不存在系统性分量，任何偏置补偿 / 残差表 / ILC 权重更新都无法降低它。
  二维各向同性高斯下 E[hypot] = 1.2533*sd = 1.2533*2.90 = 3.63，实测 3.41，完全吻合。

【关键病理 3：dual_gain=0 的成因 —— 预注册假设已被实测否证】
  [原假设] 双簇间距换算到指令空间 X≈19 us / Y≈7.2 us，而 walk 步长 6/9/12 us
           小于 X 的晶格周期，因此每步落回两齿面之间的"坏"位置 => gain=0。
  [否证实验] 把 walk 步长改成"晶格周期匹配"的 (7,14,19) us 且放宽 max_walk=4->6，
           单点 n=20 从 3.83 cnt **恶化到 5.67 cnt**（等效 sd 3.49 -> 4.90）。
           恶化原因是试探次数从 8~9 涨到 10，单点耗时变长，漂移累积收益 > 步长收益。
           代码已回退为 (6,9,12) us + max_walk=4，并把否证结论写进注释。
  [否证后的正确解释] 晶格间距不是"步长该匹配的周期"，而是**相邻两个可稳定停驻
           位置之间的间距**。一个齿面内部并不存在更细的晶格 —— 平台在齿面内被
           量化钉住成一整片平台，平台内的误差在物理上不可达。
           因此 dual_gain=0 的真实含义是：**本次访问选中的那个齿面，其平台本身
           就离目标 >1 cnt**，任何步长都无解，只能换齿面（而换齿面只能靠 4 象限
           过冲翻转，翻转量是 14~16 cnt 的量子，跳不过去）。
           => 单齿面可达集是一个"离散平台集合"，最小非零间距 = 死区对应位移
              (4.5~10.5 cnt)，所以 mean <= 2.0 cnt 在结构上不可达。

【KPI 门禁实测（4 象限版本，verify_hardware_kpi.py，退出码 1）】
  Gate 1  H->V 伴随跳动 4.19 cnt (>3.0)   FAIL
  Gate 1  V->H 伴随跳动 2.79 cnt (<=3.0)  PASS
  Gate 2  25 点均值 5.99 / 最大 13.83 cnt (需 <=2.0 / <=3.5)  FAIL
  Gate 3  全屏命中 12/12  PASS；平均光误差 4.38 cnt (需 <=2.0)  FAIL

【物理极限推导】
  实测死区/量化步长 q ≈ 6~14 us（早前 +12/-12 us 微推只产生 (5,14) counts）
  X 名义增益 0.75~0.90 cnt/us  =>  q 对应 4.5~10.5 counts
  落点 sd 3.1~3.8 cnt 换算伺服角 ≈ 0.22~0.27 deg
  MG996R 为模拟舵机（电位器反馈 + 固定死区），0.2 deg 级死区是其固有指标。
  => 本执行器上可达误差下限 mean ≈ 3.4~3.8 cnt ≈ 27~30 um
  => Gate 2/3 要求 mean <= 2.0 cnt (15.9 um)，在 MG996R 上物理不可达
  => 算法侧已无可挖掘空间：残差零偏置（不可补偿）、指令已进入死区平台（不可细分）、
     单齿面可达集是离散平台集合（平台最小间距 4.5~10.5 cnt，结构上跨不过去）

【结论：进 定案4 —— 换输出轴编码器总线舵机】
  换 STS3215 (4096 分辨率) 后方差项从"模拟舵机死区"变为"编码器量化 + 齿隙"：
    14.3 cnt/deg × (360/4096 deg) = 1.257 cnt/encoder step
    内部 200 Hz 闭环 + 输出轴编码器 => 落点误差约 ±1 step => mean 约 1.0~1.5 cnt
  这才是唯一可能同时满足 Gate1/2/3 的路径。

【本次 3 次重复给出的一个额外事实】
  场次编号越大（越晚），BASE 越低（7.474 -> 7.059 -> 6.282），DUAL 却无此趋势。
  说明 BASE 的水平受"全场热/润滑状态"影响显著，而 DUAL 的四象限过冲把齿面
  重新锁定，反而降低了这种状态依赖 —— 这与 n=20 单点测试里 DUAL 抑制漂移的
  观察一致。但这也意味着：**在本台上做 <2 cnt 的定量比较时，会话漂移
  (BASE 25 点均值跨会话 5.29~7.47，摆动约 35%) 与待验证的差距同量级**，
  继续在此执行器上调算法，测得的变化无法与漂移区分。
