  目标幅度 = 40 cnt   runs/group = 5   settle = 0.6s
  u0_kin = [1496.00, 1466.00] us

  [A] 单轴+(40us)  dx = +37.40+-1.52 cnt   dy = +5.20+-2.39 cnt | 单轴增益 = 0.925 cnt/us
  [B] 协同+        dx = +70.20+-3.35 cnt   dy = +11.40+-3.91 cnt | 跟随误差 = +29.00 cnt
  [C] 协同-        dx = +0.60+-1.34 cnt   dy = -0.40+-0.89 cnt | 跟随误差 = +40.00 cnt

  X 正反向对称性: |B| - |C| = +69.00 cnt
  单轴增益 / J[0][0] = 0.777   (接近 1 说明单轴激励量到的就是约束柔度，无额外损耗)

  H1 判据: |dx-40| = 29.00 cnt (<= 8.0)  |dy| = 12.00 cnt (<= 3.0)

  [结论 H2] 协同激励下位移仍与指令不符 => K_lin 尺度/符号存在真实偏差。
      => 这不是精度极限问题，而是标定问题，会影响所有目标定位；
         必须先重标 K_lin（或在 evaluate_kinematic_pulse 上加一次尺度校正），
         在此之前暂停一切「精度上限 / 死区量化」结论。
