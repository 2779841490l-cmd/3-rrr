# B1 双相限时脉冲（Kick-and-Hold）重复性判决书

> 日期：2026-11-13
> 结论一句话：**B1 在 X 轴（S1 单缸）可重复达标；在 Y 轴（S2/S3 差动双缸）两个方向均不可重复。
> 按外部专家「四方向全部 ≥PASS 才允许拼接」的判据，B1 不得原样替换 `_dual_side_refine` 的阶梯。**
> 同时，专家的核心否决（静态 `(45,25,12)` 阶梯必败）被第四次独立复现证实。

---

## 一、判决实验：同一配方在同会话内连跑三块 × 六发

方法：把 `scratch_b1_2d_sweep.py` 的 `--kicks` 写成三个相同值，网格循环即对**同一单元格**
重复三次，块间隔约 6 s，全程逐发落盘 CSV。判据沿用专家原始标准：
**|mean| ∈ [2, 5] counts 且 sd ≤ 2 counts**。

| 方向 | 驱动方式 | Block 1 | Block 2 | Block 3 | 三块汇总判定 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **X+** | S1 单缸 | **+4.17 ± 0.98** | **+4.83 ± 0.75** | **+4.83 ± 1.17** | ✅ **3/3 PASS，可重复** |
| **X−** | S1 单缸 | −4.83 ± 2.23 | −5.17 ± 1.60 | **−4.67 ± 0.52** | ⚠️ 均值稳定（−4.67~−5.17）但重尾（−8/−9），1/3 PASS |
| **Y+** | S2 + S3 差动 | +5.67 ± 3.61 | +4.83 ± 2.64 | **+2.50 ± 0.84** | ❌ 均值漂移 2.5→5.7，尾巴 +12，1/3 PASS |
| **Y−** | S2 + S3 差动 | **−4.67 ± 1.03** | −8.83 ± 6.18 | −8.33 ± 6.86 | ❌ 崩溃，尾巴 −17/−21，1/3 PASS |

配方：
- X+ = `jac0 / sign=+1 / kick=45 / hold=−12 / dt=20 ms`
- X− = `jac0 / sign=−1 / kick=38 / hold=−11 / dt=20 ms`
- Y+ = `jac1 / sign=+1 / kick=21 / hold=−3 / dt=20 ms`
- Y− = `jac1 / sign=−1 / kick=27 / hold=−5 / dt=19 ms`

证据文件：
- `experiments/b1_2d_sweep_jac0_p1_20261113_014232.csv`（18 发）
- `experiments/b1_2d_sweep_jac0_m1_20261113_014300.csv`（18 发）
- `experiments/b1_2d_sweep_jac1_p1_20261113_014329.csv`（18 发）
- `experiments/b1_2d_sweep_jac1_m1_20261113_014357.csv`（18 发）
- 四方向汇总（n=8）：`experiments/b1_four_dir_confirm.csv`

## 二、跨会话漂移：比块内方差更致命

Y− 的最佳单元格 `kick=27 / hold=−5 / dt=19` 在 20 分钟内两次测量：

| 时刻 | 测量 | 结果 |
| :--- | :--- | :--- |
| T−20 min | n=6 单块 | **−3.00 ± 1.90** ✅ |
| T+0 | 三块 | **−15.33 ± 4.08** / **−8.33 ± 6.77** / **−7.50 ± 3.39** ❌ |

同一份代码、同一台机器、同一次开机。差别只有「这段时间里平台跑了上百发脉冲」。
**⇒ Y 轴的微步落点依赖脉冲历史（接触/预滑动状态记忆），不是一个可标定的常量。**

Y+ 也有同类证据：`kick=21 / hold=−3 / dt=20` 在 `scratch_b1_four_dir_confirm.py`（n=8）
测得 `+3.63 ± 1.60`，在 `scratch_b1_2d_sweep.py`（n=5）测得 `+2.20 ± 1.10`。

## 三、物理归因：X 是单缸、Y 是差动双缸

`RectangularManifoldController.evaluate_pulse()` 只输出两个自由度 `(ux, uy)`；
驱动层按和锁推导 `s3 = 3000 − uy`（见 `rect_manifold_calibrator.py:182-185`）。

| 自由度 | 执行器 | 约束 | 微步可靠性 |
| :--- | :--- | :--- | :--- |
| X | S1（GPIO 2）单缸 | 无 | ✅ 可重复 |
| Y | S2（GPIO 5）+ S3（GPIO 7）差动对 | `u2 + u3 = 3000 µs` | ❌ 重尾 / 双重峰 |
| Micro-Yaw | S4（GPIO 8） | — | 本次未涉及 |

**假设 H（待定案3 验证）**：差动对要求两条腿**同时**越过各自的静摩擦阈值。
若 S2 与 S3 的预滑动相位/阈值不一致，则先动的腿把平台拖出一个偏摆，
机构在闭合链内被迫弹性储能；一旦后动的腿崩塌，储能释放 ⇒ 位移出现
「一个滑移量子」的跳变。这正好复现观测到的双重峰（0 或 ~17）与重尾（−17/−21）。

**该假设的判据**：单独扫描 S2 与 S3 的启停阈值，若两者差值明显非零即可确认。

## 四、本轮被数据否证的若干假设（避免重复踩坑）

| 假设 | 否证证据 |
| :--- | :--- |
| 串口写入是瓶颈 | `send_raw_pulses` 实测 **0.32 ms** |
| WS63 固件存在斜坡限速 | 固件以 **50 µs** 切片轮询 `g_cmd_updated`，新指令 ≤1 帧（~5 ms）生效；`ramp_xy_interruptible` 只存在于 `servo_test_3rrr_backup.c` |
| 静态微偏置可以当微步 | `hold = −12 µs` 单独施加 ⇒ **+0.00 ± 0.00 cnt** |
| B1 是伪机制（kick 从未落地） | dt 扫描单调：`0→+0.00 / 5→+1.67 / 10→+1.67 / 20→+4.67 / 35→+7.00 / 50→+13.67 / 70→+18.67` |
| 小幅 kick 更安全、方差更小 | Y− 相反：kick=23 ⇒ sd 4.64；kick=26 ⇒ sd 0.84 |
| 尾巴随 kick 单调增长 | Y− 相反：低 kick 落在触发阈值附近 ⇒ 时灵时不灵（双峰） |
| 网格不够密 | 同一格连跑三块就漂 1~12 counts，与网格密度无关 |
| `dt=22 ms` 比 `dt=20 ms` 更好 | 悬崖：X−/Y− 在 dt=20 时 sd 0.45~0.89，dt=22 炸到 2.17~3.36 |

## 五、对 `_dual_side_refine` 拼接的含义

1. **静态 `(6, 9, 12) µs` 阶梯必须继续被否决**：已四次独立实测其为死步。
   这同时解释了历史记录中 `max_walk=6` 的发散（3.83 → 5.67 cnt）。
2. **B1 也不能原样替换**：只有 X+ 达到专家判据，Y 两个方向不达标。
   按「禁止只挑好方向拼」的铁律，**不得拼接**。
3. `step_dir = self.manifold.K_trim @ err_vec`（`rect_manifold_calibrator.py:846`）
   的方向错误依然要修：`K_trim` 列 2 相对真实逆雅可比偏约 24°，
   造成 +7.3 counts 寄生 X；正确来源是 `calib_params.json` 的
   `inverse_jacobian_center_us_per_px` 归一化列。
   **这一项与 B1 是否可拼接无关，可以独立先行修复。**

## 六、建议的下一步（按优先级）

1. **定案3：S2 / S3 双缸启停阈值差分** —— 直接检验假设 H。
   这是唯一能把「Y 轴不可控」从玄学变成可补偿参数的实验。
2. **路线 D：脉冲内闭环中途修正** —— 唯一能吸收「±滑移量子」的方案。
   `probe_target_brake.py` 需先修正 `DRIVE_CAP_MS`（当前 40 ms 短于实测运动起始 ~35 ms），
   再以「读到目标即刻撤驱动」闭环截断。
3. **X 轴先行落地** —— X+ 的 B1 已满足判据，可作为「X 轴专用微步」单独接入，
   Y 轴暂用闭环/二分，不阻塞 X 方向的精度推进。

## 七、一句话给论文的素材

> 在低成本 3-RRR 的差动双 Y 驱动上，开环微步的落点不是常量而是**接触状态的函数**：
> 同格重复三块的均值漂移可达 12 counts（−15.3 → −7.5），而单缸 X 轴的同一手法
> 在三块内保持 +4.17~+4.83（sd < 1.2）。**这是负结果，但正是「为何必须做脉冲内闭环」的
> 定量论据**，可直接支撑路线 D 的必要性。
